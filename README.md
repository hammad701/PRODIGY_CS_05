# Network Packet Analyzer (Ethical) 📡

This project is a **PCAP-based Network Packet Analyzer** developed in Python as **Task-05** during a **Cyber Security Internship at Prodigy InfoTech**.

The tool analyzes captured network traffic from PCAP files and displays relevant packet information for educational purposes.

---

## ⚠️ Ethical Use Notice

This tool does NOT perform live packet sniffing.

- No real-time network capture
- No monitoring of other users
- No interception of private traffic
- Works only with user-provided PCAP files

Designed strictly for **learning and ethical analysis**.

---

## 🛠️ Features

- Reads packets from PCAP files
- Displays source and destination IP addresses
- Identifies network protocols (TCP/UDP)
- Shows payload previews
- Simple and beginner-friendly CLI interface
